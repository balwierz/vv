## VCF / BCF

`.vcf` `.vcf.gz` `.bcf` — `INFO` is split into typed columns from the
`##INFO` header, and each sample is a struct typed from `##FORMAT`
(`{GT: 0/1, AD: [9, 8], DP: 17, …}`). Region queries use the tabix / CSI index.

![vv: a 6-sample VCF in the interactive viewer](img/vv/vcf.svg)

`Enter` opens the record:

![vv: record detail with the sample structs](img/vv/vcf-detail.svg)

Per-variant genotype counts (`--gt-stats`) and a region query:

![vv --gt-stats](img/vv/gt-stats.svg)
![vv -r on a tabix-indexed VCF](img/vv/region.svg)

![vvg: the same VCF with the row-detail dock](img/vvg/vcf.png)

Try: `vv calls.vcf.gz` · `vv -r chr17:43044295-43125483 calls.vcf.gz` ·
`vv --samples long --filter 'GT == "1/1"' calls.vcf.gz`.
More: [range queries](USAGE.md#range-queries--r---regions-file---slop),
[`--samples`](USAGE.md#sample-columns---samples),
[`--gt-stats`](USAGE.md#--gt-stats-vcfbcf-genotype-aggregates).

## BAM / CRAM / SAM / PAF

`.bam` `.cram` `.sam` `.paf` — one row per alignment; FLAG filters by name
(`FLAG lacks UNMAP,DUP`), `--tags NM,AS` adds typed aux-tag columns,
`--pileup -f ref.fa` gives samtools-style pileup rows.

![vv: a coordinate-sorted BAM](img/vv/bam.svg)

![vv: minimap2 PAF](img/vv/paf.svg)

![vvg: a BAM with the row-detail dock](img/vvg/bam.png)

Try: `vv -r chr17:43044295-43050000 reads.bam` ·
`vv --filter 'MAPQ >= 30 and FLAG lacks DUP' --tags NM reads.bam` ·
`vv --contigs reads.bam`.
More: [`--tags`](USAGE.md#--tags-list-bam--cram--sam-aux-tags),
[`--contigs`](USAGE.md#--contigs-reference-sequences--assembly).

## BED and ENCODE peaks

`.bed` `.narrowPeak` `.broadPeak` `.gappedPeak` `.bedGraph` `.tagAlign`
(plain, `.gz`, `.zst`) — named, typed columns (`signalValue`, `pValue`, …);
BED `itemRgb` is drawn as a colour swatch.

![vv: an ENCODE narrowPeak file](img/vv/narrowpeak.svg)

Try: `vv peaks.narrowPeak` · `vv --sort signalValue:desc -n 20 peaks.narrowPeak` ·
`vv -r chr1:1000000-2000000 peaks.bed.gz`.

## GFF / GTF

`.gff` `.gff3` `.gtf` (plain, `.gz`, `.zst`) — the nine columns; `--expand
attributes` unpacks the attribute column into one column per key.

![vv: a GFF3 gene annotation](img/vv/gff3.svg)

Try: `vv --expand attributes --filter 'feature == "gene"' --select seqname,start,end,Name genes.gff3`.

## FASTA / FASTQ

`.fa` `.fasta` `.fna` `.faa` `.fq` `.fastq` (plain or gzip / bgzf) — one row per
record; `--seq-stats` summarises a file (N50, GC, Q20).

![vv: FASTQ reads](img/vv/fastq.svg)
![vv: FASTA records](img/vv/fasta.svg)
![vv --seq-stats](img/vv/seq-stats.svg)

Try: `vv reads.fq.gz` · `vv --seq-stats reads.fq.gz` ·
`vv --filter 'name ~ "^chr17"' genome.fa`.
More: [`--seq-stats`](USAGE.md#--seq-stats-fasta--fastq-summary).

## bigWig / bigBed / 2bit

`.bw` `.bigWig` `.bb` `.bigBed` `.2bit` — bigWig intervals and values, bigBed
records typed from their embedded autoSql, 2bit sequence index; region queries
use the file's own index.

![vv: a bigWig](img/vv/bigwig.svg)

Try: `vv -r chr17:43044295-43125483 coverage.bw` · `vv genome.2bit`.
More: [bigBed / bigWig](USAGE.md#bigbed--bigwig-specifics).

## mpileup

`.pileup` `.mpileup` `.pile` (plain, `.gz`, `.zst`) — per-base rows; a
multi-sample file gets `depth_i` / `bases_i` / `quals_i` per sample. `vv
x.bam --pileup -f ref.fa` produces the same rows from a BAM / CRAM.

Try: `vv sample.mpileup.gz -r chr1:1000-2000` · `vv reads.bam --pileup -f ref.fa -r chr17:43045000-43045100`.

## PLINK and TSV layouts

`.bim` `.fam` `.pvar` `.psam`, `.bedpe` `.pairs` `.gct` `.maf` — each read
with its own header convention (PLINK 2 column names, bedtools' BEDPE names,
GCT's dimension and metadata lines kept out of the data). A PLINK `.bed` /
`.pgen` genotype file is refused with the `plink2` command that converts it.

Try: `vv data.bim` · `vv expression.gct`.

## AnnData / HDF5 / Loom / 10x

`.h5ad` `.h5` `.hdf5` `.loom`, Cell Ranger `filtered_feature_bc_matrix.h5` and
`matrix.mtx` directories — a summary tab (shapes, storage, a per-matrix value
profile) and one tab per component: `X`, `obs`, `var`, `obsm`, `varm`,
`layers`, `obsp`, `uns`. Sparse matrices are previewed, not densified; `--tab X
--parquet` exports the whole matrix.

![vv: AnnData summary tab](img/vv/anndata.svg)
![vv: AnnData obs tab](img/vv/anndata-obs.svg)

![vvg: AnnData obs with the row-detail dock](img/vvg/anndata.png)

Try: `vv pbmc.h5ad` · `vv --tab obs --filter 'cell_type == "B"' pbmc.h5ad` ·
`vv --tab X --matrix long --tsv pbmc.h5ad > counts.tsv`.
More: [`--schema`](USAGE.md#--schema), [`--matrix`](USAGE.md#data-exploration).

## MatrixMarket

`.mtx` `.mtx.gz` — coordinate entries as `row`, `col`, `value` (0-based), shape
and entry count in the footer. A 10x / STARsolo directory opens as labelled
`matrix` / `features` / `barcodes` tabs.

![vv: a MatrixMarket file](img/vv/mtx.svg)

Try: `vv matrix.mtx.gz` · `vv filtered_feature_bc_matrix/`.

## NumPy

`.npz` `.npy` — a summary tab plus one tab per array; 1-D arrays are a column,
2-D a table, 3-D+ are 2-D slices stepped with `[` / `]`.

![vv: an .npz archive](img/vv/npz.svg)

Try: `vv embedding.npz` · `vv --tab umap --tsv embedding.npz`.

## Parquet / Arrow / ORC

`.parquet` `.lociss` `.arrow` `.feather` `.arrows` `.orc` — the first screen
decodes only the row groups it needs; nested, temporal, decimal and dictionary
columns are shown as values. `S` opens column statistics; `--schema` and
`--describe` print them.

![vv: an ATAC peak Parquet](img/vv/parquet.svg)
![vv: column statistics (S)](img/vv/parquet-stats.svg)
![vv --schema](img/vv/schema.svg)
![vv --describe](img/vv/describe.svg)

![vvg: filtered and sorted Parquet](img/vvg/parquet.png)

Try: `vv peaks.parquet` · `vv --filter 'signal > 10' --sort signal:desc peaks.parquet` ·
`vv -r chr1:1000000-2000000 peaks.parquet`.
More: [`--describe`](USAGE.md#--describe), [`--stats`](USAGE.md#--stats-parquet-only),
[LociSSD](USAGE.md#locissd-specifics).

## TSV / CSV

`.tsv` `.csv` (plain, `.gz`, `.zst`; other extensions by content) — types are
inferred; `##` preambles, R-style row names and quoted `NA` are handled.

![vv: a TSV table](img/vv/table.svg)

Try: `vv samples.tsv` · `vv --filter 'age > 40' --select sample,age samples.tsv` ·
`vv -d ';' export.txt`.

## Excel / ODS / SQLite

`.xlsx` `.xlsm` `.ods` `.fods` `.sqlite` `.sqlite3` `.db` — one tab per sheet or
table; `--tab NAME` picks one from the command line.

![vv: an Excel workbook](img/vv/xlsx.svg)
![vv: an SQLite database](img/vv/sqlite.svg)

![vvg: an SQLite database](img/vvg/sqlite.png)

Try: `vv lab.sqlite` · `vv --tab qc --tsv samples.xlsx`.

## Directories and datasets

`vv DIR/` — the Parquet / Arrow / ORC / CSV / TSV / JSON files under a directory
as one table; Hive `key=value/` path components become columns.

![vv: a Hive-partitioned Parquet dataset](img/vv/dataset.svg)

Try: `vv measurements/` · `vv --filter 'assay == "WGS"' measurements/`.
More: [directories](USAGE.md#directories-and-partitioned-datasets).

## JSON / NDJSON

`.json` `.ndjson` `.jsonl` `.geojson` `.ipynb` `.har` (plain, `.gz`, `.zst`, or on stdin) — on a terminal
a document opens in a folding tree (jq paths, search, copy, `t` for a table of
records); in a pipe it is re-indented, or listed as `path = value` lines with
`--json-paths`. NDJSON / record arrays are tables with any table flag.

![vv: JSON tree viewer](img/vv/json-tree.svg)
![vv --json-paths](img/vv/json-paths.svg)
![vv: NDJSON records as a table](img/vv/ndjson.svg)

![vvg: a JSON document as a tree](img/vvg/json-tree.png)
![vvg: NDJSON records](img/vvg/json.png)

Try: `vv run.json` · `curl -s https://api.github.com/repos/balwierz/vv | vv -` ·
`vv --json-paths run.json | grep metrics`.
More: [JSON documents](USAGE.md#json-documents).

## Markdown

`.md` `.markdown` — rendered with colour; GFM tables go through vv's table
renderer; local images are shown inline on kitty / iTerm2 / WezTerm.

![vv: a Markdown file](img/vv/markdown.svg)

## Plain text and logs

`.txt` `.log` (plain, `.gz`, `.zst`) and any other file that sniffs as text —
a `less -SN`-like view with line numbers, sideways scrolling, `/` search and `&`
filter; ANSI colours in the file are kept. Binary files are refused, not dumped.

![vv: a coloured pipeline log](img/vv/log.svg)

Try: `vv pipeline.log` · `vv --filter 'line contains "ERROR"' pipeline.log`.
More: [plain text](USAGE.md#plain-text-txt-log-and-the-sniffed-fallback).

## Stdin

`vv -` reads from a pipe: text formats stream as they arrive (gzip / zstd
decoded); binary formats are copied to a temporary file first. Process
substitution works the same way.

Try: `zcat calls.vcf.gz | vv -` · `vv <(curl -s https://example.org/data.parquet)`.
More: [stdin](USAGE.md#stdin).
