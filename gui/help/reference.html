Field reference

How to use vvg, the syntax of its Filter, Find and Region boxes, and what the columns, keys and codes of common genomics files mean. Thresholds quoted are the tools' own published defaults; they are starting points, not clinical criteria. Type in the box above to search; Enter finds the next match.

Using vvg

OpenOpen (Ctrl+O; its ▾ lists the recent files), Open Directory (a directory of Parquet / CSV / JSON parts as one dataset, Hive key=value/ directories as columns) or drag files onto the window. Every format vv --formats lists opens here.
TabsA file of several parts (AnnData, a workbook, a database, HDF5, NumPy archive, R data) opens one tab per part; a tab reads its file when first shown. With several files open each file's tabs are underlined in a colour of their own and the first names the file. Right-click a tab: Close File (Ctrl+Shift+W), Close Other Files, Copy Path.
SortClick a column header: ascending, then descending, then the file's order. Numbers sort as numbers, dates as dates.
FilterThe Filter box (Ctrl+Shift+F): keep the rows matching an expression (see Filter expressions); Enter applies. Right-click a cell for Filter to / Exclude its value (or the selected values of its column), added to the current filter.
FindThe Find box (Ctrl+F): highlight cells matching a regular expression; Enter or F3 jumps to the next match.
Format optionsUnder the tab bar, the options the current tab's file offers and nothing else: Region (Ctrl+L), Pileup and Tags (BAM / CRAM), Samples and GT stats (VCF / BCF), Expand (VCF INFO, GFF / GTF attributes), Contigs, Matrix wide / long (AnnData, Loom, 10x, Zarr), Slice (NumPy arrays of 3+ axes). They apply to that file's tabs only.
CopyCtrl+C copies the selected cells as tab-separated text, Ctrl+Shift+C whole rows; Ctrl+Alt+C copies the vv command that prints the current view.
ExportCtrl+E writes the current tab's view (filter, sort, visible columns, every row) to Parquet, Arrow, TSV, CSV or JSON.
DetailsCtrl+B shows the panel on the right: the cursor row, one field per line, and the cursor column's statistics (counts, distinct values, range, mean, quantiles).
Columns, rowsView ▸ Columns shows and hides columns; Ctrl+G goes to a row. View ▸ Column Types shows or hides each column's type under its name (see Column types).
MenuF10 or the ≡ button; right-click the toolbar for the same. View ▸ Menu Bar shows the classic menus.
KeysHelp ▸ Keyboard Shortcuts (Ctrl+/) lists every command with its key; Help ▸ Find Action (Ctrl+Shift+P) runs one by typing part of its name.

Filter expressions

The same language as vv --filter: conditions column operator value, joined by and / or (and binds tighter). Words are case-insensitive.

== != < <= > >=Compare. Numbers compare as numbers; text in quotes, "chr1" or 'chr1'; a date or timestamp column takes a quoted date: day > "2024-01-01", ts < "2024-06-15 12:30Z"; a boolean column takes true / false.
~ !~Matches / does not match a regular expression (ECMAScript), anywhere in the text: Gene ~ "^BRCA".
contains, startswith, endswithText tests without a regular expression: name contains "kinase".
in, not inSet membership: chrom in ("chr1", "chr2"); in @ids.txt reads the members from a file, one per line (its first tab-separated field).
is null, is not nullMissing values: FILTER is null.
has, lacksBits of an integer column, all set / none set, as numbers or SAM FLAG names: FLAG lacks UNMAP,SECONDARY,DUP (PAIRED, PROPER_PAIR, UNMAP, MUNMAP, REVERSE, MREVERSE, READ1, READ2, SECONDARY, QCFAIL, DUP, SUPPLEMENTARY).
`Column name`A name with spaces or symbols goes in backticks: `Sample ID` == "S1" (two backticks stand for one).
Examplesscore > 5 and chrom == "chr1"
FILTER is null or Gene ~ "^BRCA"
MAPQ >= 30 and FLAG lacks DUP

Find

A regular expression (ECMAScript), case-insensitive, matched anywhere in a cell's text as shown: ^chr(1|2)$, rs[0-9]+, BRCA[12]. Matching cells are highlighted; Enter or F3 moves to the next one.

Region

chr1:1,000-2,000 (commas optional), several separated by commas; a chromosome alone means all of it. With 0-based (the default) the numbers are BED-style, half-open; with 1-based they are inclusive, as in samtools, tabix, VCF and GFF. slop widens each window on both sides. A region needs an index: .bai / .csi / .crai for BAM / CRAM, .csi / .tbi for BCF, tabix (bgzip + tabix -p vcf|bed|gff) for text, .fai for FASTA. Parquet with chromosome / start / end columns, LociSSD, bigBed / bigWig, Cooler and GenBank need none. An unindexed text file is read in full and filtered.

Coordinates

File formats keep their own convention: BED, bigBed, bigWig, bedGraph, narrowPeak and BEDPE are 0-based, half-open, so chr1:0-1000 is the first 1000 bases; VCF, GFF3, GTF and SAM are 1-based and inclusive. A VCF POS of 100 is the BED interval 99–100. vvg shows each file's numbers as stored.

Column types

The second line of a column header is its type, in Apache Arrow's terms.

int8 … int64, uint8 … uint64Whole numbers, signed or not, of 8 to 64 bits.
float, double, halffloatFloating-point numbers of 32, 64 and 16 bits.
decimal128(p, s)Exact decimals: p digits, s of them after the point.
string, large_stringText (UTF-8). binary is raw bytes.
booltrue / false.
date32[day], timestamp[unit, tz]A calendar day; a point in time to the unit (s, ms, us, ns), in UTC when tz is given. duration[unit] is a length of time.
list<element: T>A list of values of type T per cell (VCF multi-valued keys, Parquet arrays).
struct<a: T, b: U>Named fields per cell (VCF samples with Samples ▸ struct).
map<K, V>Key → value pairs per cell.
category[string]A categorical (dictionary) column: each value is one of a fixed set, stored once (AnnData categoricals, R factors, Parquet dictionaries); ordered when the set has an order.

AnnData, MuData, Loom

An .h5ad file (and AnnData in Zarr) holds a matrix of observations (usually cells) × variables (genes) with tables and arrays aligned to either axis. The summary tab lists them by their names in the file, as code reaches them (adata.obsp["distances"]).

XThe main matrix, cells × genes; dense, or sparse as CSR (rows stored) or CSC (columns stored). Often normalised; then raw counts are in layers or raw. Shown as a preview tab; Matrix ▸ long lists one row per stored value.
obs, varTables with one row per cell / per gene: QC metrics, cluster labels, gene names and IDs.
obsm, varmArrays with one row per cell / gene and several columns: embeddings (X_pca, X_umap), PCA loadings (PCs).
obsp, varpSquare cell × cell (gene × gene) matrices: the neighbour graph (connectivities, distances). Each opens as an edge list: i, j, the two names, weight.
layersMatrices of X's shape: other versions of the data (counts, spliced / unspliced, scaled values).
raw.X, raw.varThe copy scanpy keeps before genes are filtered: all genes, often raw or log-normalised counts.
unsUnstructured metadata: parameters of the analysis steps, colour palettes, neighbour settings.
profile, storageSummary rows vv adds: a matrix's value type, stored fraction and range (whole non-negative numbers look like raw counts), and its encoding, chunking, compression and size on disk.
MuData (.h5mu)Several AnnData objects, one per modality (rna, atac, prot), with joint obs / var; tabs read rna:X, rna:obs, ….
Loommatrix stored genes × cells (shown cells × genes), layers, row_attrs per gene, col_attrs per cell, row_graphs / col_graphs.

VCF: the columns

CHROM, POSChromosome and the 1-based position of the first REF base. For indels POS is the base before the event (the "padding" base shared by REF and ALT).
IDIdentifiers, usually a dbSNP rsID; "." when none.
REF, ALTReference and alternative alleles. Several ALT alleles are comma-separated; * is an allele spanning a deletion upstream; <DEL>, <DUP>, <INV>, <CNV> are symbolic structural alleles; <NON_REF> (gVCF) stands for any unobserved allele.
Quality (QUAL)Phred-scaled confidence that the site is variant: QUAL = −10·log10 P(no ALT allele here). 20 means 1 % chance of a false call, 30 means 0.1 %. Callers differ in calibration; GATK's hard filter flags QUAL < 30.
Filter (FILTER)PASS if every filter passed, otherwise the codes of the filters that failed (semicolon-separated), each described in a ##FILTER header line; "." means no filters were applied.
INFOSite-level annotations, KEY=value or flags, each declared in a ##INFO header line with its type and Number (A: one per ALT allele, R: one per allele including REF, G: one per genotype, 0: a flag).
FORMAT, samplesThe per-sample keys (e.g. GT:AD:DP:GQ:PL) and each sample's values in that order.

VCF INFO: the specification's keys

Allele count (AC)How many times each ALT allele appears in the called genotypes (a heterozygote counts 1, a homozygote 2).
Allele number (AN)Total number of alleles in called genotypes: twice the number of diploid samples with a call. Missing genotypes lower AN.
Allele frequency (AF)Frequency of each ALT allele, normally AC/AN within this file's samples (not a population frequency unless the file is a population resource).
Depth (DP)Combined read depth at the site across samples, often after the caller's read filters; per sample in FORMAT.
Mapping quality (MQ)Root mean square of the mapping qualities of the reads at the site. Low values point to repetitive or paralogous sequence; GATK's hard filter flags MQ < 40.
MAPQ 0 reads (MQ0)Number of reads with mapping quality zero (placed equally well elsewhere).
Samples with data (NS)Number of samples with data at the site.
Strand bias (SB)Strand bias at the site; in GATK's per-sample form, four counts: REF forward, REF reverse, ALT forward, ALT reverse.
Ancestral allele (AA)The allele inferred to be ancestral (from primate alignments).
In dbSNP (DB)Flag: the variant is in dbSNP. H2/H3 and 1000G flag membership of HapMap and 1000 Genomes.
Somatic (SOMATIC)Flag: the record is a somatic mutation (cancer genomics).
End position (END)The last position of the record (structural variants, gVCF reference blocks).
SV type (SVTYPE)DEL, DUP, INS, INV, CNV or BND (a breakend; MATEID names its partner). SVLEN is the length (negative for deletions in older files).
Position CI (CIPOS)Confidence interval around POS (and CIEND around END) for imprecise structural variants (IMPRECISE).

VCF INFO: GATK's site annotations

GATK's recommended hard filters (when VQSR or VETS cannot be used): for SNPs QD < 2.0, QUAL < 30, SOR > 3.0, FS > 60.0, MQ < 40.0, MQRankSum < −12.5, ReadPosRankSum < −8.0; for indels QD < 2.0, QUAL < 30, FS > 200, ReadPosRankSum < −20.0. Keys starting with AS_ are the same annotations computed per ALT allele.

Quality by depth (QD)QUAL divided by the allele depth of the samples carrying the variant. Normalises QUAL for coverage: a high QUAL from very deep data with weak allelic support still gives a low QD. Low QD (< 2) suggests a false positive.
Fisher strand bias (FS)Phred-scaled p-value of Fisher's exact test on the 2 × 2 table of REF/ALT reads by forward/reverse strand. 0 means no evidence of bias; high values mean the ALT allele is seen mostly on one strand, a common sequencing or mapping artefact.
Strand odds ratio (SOR)Strand bias as a symmetric odds ratio of the same 2 × 2 table, which, unlike FS, does not grow with depth alone. Values above 3 (SNPs) suggest bias.
Mapping quality rank sum (MQRankSum)z-score of the Wilcoxon (Mann–Whitney) rank-sum test comparing the mapping qualities of ALT-supporting reads with REF-supporting reads in heterozygotes. Near 0 is good; strongly negative means ALT reads map worse, as at paralogous sequence.
Read position rank sum (ReadPosRankSum)The same rank-sum test on the position of the variant within the reads. Strongly negative means the ALT allele sits mostly near read ends, where errors and misalignments gather.
Base quality rank sum (BaseQRankSum)The rank-sum test on base qualities: negative means ALT bases have lower quality than REF bases.
Clipping rank sum (ClippingRankSum)The rank-sum test on the number of clipped bases per read: ALT reads clipped more often hint at a structural event or misalignment.
Excess heterozygosity (ExcessHet)Phred-scaled p-value of an exact test (Wigginton, Cutler & Abecasis 2005) that the cohort holds more heterozygotes than Hardy–Weinberg equilibrium predicts from the allele frequency. A real germline variant in an outbred cohort should not show strong excess; high values (GATK flags > 54.69, i.e. p < 3.4 × 10−6) usually mean reads from two paralogous loci collapsed onto one, or a systematic genotyping error. Needs a cohort; meaningless for a single sample.
Inbreeding coefficient (InbreedingCoeff)F = 1 − (observed heterozygotes / expected heterozygotes) under Hardy–Weinberg equilibrium, across the cohort. Positive values: fewer heterozygotes than expected (inbreeding, population structure, or allele dropout). Strongly negative: excess heterozygotes, as above; gnomAD filters sites with F < −0.3. Needs about ten or more samples.
VQSR log odds (VQSLOD)Variant Quality Score Recalibration: the log odds that the variant is true rather than an artefact, from a Gaussian mixture model trained on known variants over the annotations above. Higher is better; the VQSRTranche… filters cut at sensitivity levels (e.g. "99.90to100.00" holds the lowest-scoring calls kept only to reach 99.9–100 % sensitivity). culprit names the annotation that weighed most against the call.
ML allele count (MLEAC)Maximum-likelihood estimate of the allele count (and MLEAF of the frequency), which may differ from AC when genotypes are uncertain.
Downsampled (DS)Flag: reads were downsampled at this site.
Tumour log odds (TLOD)Mutect2: log10 likelihood ratio that the variant is present in the tumour versus absent. NLOD: the evidence that the normal sample does not carry it. POPAF: −log10 of the population allele frequency used as a germline prior. GERMQ: Phred-scaled probability that the variant is germline.
Tandem repeat (STR)Flag: the variant is a short tandem repeat expansion or contraction; RU is the repeat unit and RPA the number of units in REF and each ALT.

VCF FORMAT: per-sample keys

Genotype (GT)Allele indices: 0 is REF, 1 the first ALT, 2 the second… / unphased, | phased (the order is the haplotype), . missing. 0/1 heterozygous, 1/1 homozygous ALT, 1/2 two different ALT alleles; a single index is a haploid call (chrY, chrM, males' chrX outside the PARs).
Allele depths (AD)Reads supporting each allele, REF first. The allele balance ADALT/DP of a germline heterozygote is near 0.5; far lower values suggest mosaicism, contamination or an artefact.
Genotype quality (GQ)Phred-scaled confidence that the GT is correct, given that the site is variant: in GATK the difference between the two smallest PL values, capped at 99. GQ 20 means 1 % chance the genotype is wrong.
Genotype likelihoods, Phred (PL)−10·log10 likelihood of each possible genotype, normalised so the most likely is 0. For one ALT allele the order is 0/0, 0/1, 1/1; e.g. 250,0,300 strongly favours 0/1. GL holds the same as log10 likelihoods; GP posterior probabilities.
Phase set (PS)Genotypes with the same phase set are phased relative to each other. PGT/PID are GATK's physical (read-backed) phasing.
Reference genotype quality (RGQ)gVCF: confidence that a sample is homozygous REF where no variant was called. MIN_DP is the lowest depth within a reference block.
Sample filter (FT)Per-sample filter status, like FILTER.
Variant allele fraction (AF, VAF)Somatic callers (Mutect2's AF): estimated fraction of reads carrying the ALT allele in that sample.
F1R2 / F2R1 orientation countsMutect2: reads supporting each allele by read orientation; a strong imbalance flags oxidation (OxoG) or FFPE artefacts.

dbSNP

Older dbSNP VCFs (to build 151) carry many flags; newer ones (build 152 on) keep fewer and put frequencies in FREQ.

dbSNP ID (RS)The rs number, without "rs". RSPOS its position; dbSNPBuildID the build that first reported it.
Variation class (VC)SNV, MNV, INS, DEL, INDEL (DIV in old files) and others.
Genes (GENEINFO)Overlapping genes as SYMBOL:NCBI-Gene-ID, several separated by "|".
Variant origin (SAO)0 unspecified, 1 germline, 2 somatic, 3 both.
Suspect reason (SSR)Why the variant is suspect, as bits: 0 none, 1 paralog, 2 from ESTs, 4 old alignment, 8 paralogous ESTs, 16 failed in 1000 Genomes, 1024 other.
Function flagsNSM missense, NSN nonsense, NSF frameshift, SYN synonymous, U3/U5 in a 3′/5′ UTR, ASS/DSS splice acceptor/donor, INT intronic, R3/R5 within 500 bp / 2 kb downstream/upstream of a gene.
1000G allele frequencies (CAF)Allele frequencies from 1000 Genomes, REF first. COMMON=1: minor allele frequency ≥ 1 % in at least one 1000 Genomes population. G5/G5A: MAF > 5 % in all / at least one population.
Frequencies by study (FREQ)Newer builds: allele frequencies per study, Study:REF,ALT… separated by "|" (e.g. GnomAD, TOPMED, 1000Genomes, ALSPAC).
TOPMed allele frequencies (TOPMED)Allele frequencies in the TOPMed program, REF first.
Publication flagsPM cited in PubMed, PMC in PubMed Central, OM in OMIM, LSD in a locus-specific database, MUT cited as a mutation, CDA tested by a clinical diagnostic assay, VLD validated.

ClinVar

Clinical significance (CLNSIG)The aggregate classification across submissions: Pathogenic, Likely pathogenic, Uncertain significance, Likely benign, Benign, combinations such as "Pathogenic/Likely pathogenic", "Conflicting classifications of pathogenicity" (submitters disagree; CLNSIGCONF lists them with counts), and non-Mendelian terms: drug response, risk factor, association, protective, Affects, other, not provided. Germline classifications follow ACMG/AMP criteria.
Review status (CLNREVSTAT)How well supported the classification is, shown on ClinVar's site as stars: practice guideline ★★★★; reviewed by expert panel ★★★; criteria provided, multiple submitters, no conflicts ★★; criteria provided, conflicting classifications ★; criteria provided, single submitter ★; no assertion criteria provided, and no classification provided: no stars. Give one-star and unstarred entries less weight.
Condition (CLNDN)The conditions the classification is for, "|"-separated; "not provided" and "not specified" are common placeholders. CLNDISDB gives their identifiers (MedGen, OMIM, Orphanet, MONDO, HPO). The …INCL keys describe haplotypes or genotypes the variant is part of.
Variant type (CLNVC)single nucleotide variant, Deletion, Duplication, Insertion, Indel, Microsatellite, … (CLNVCSO its Sequence Ontology term).
Molecular consequence (MC)Sequence Ontology term and name, e.g. SO:0001583|missense_variant.
Allele origin (ORIGIN)Bit flags: 0 unknown, 1 germline, 2 somatic, 4 inherited, 8 paternal, 16 maternal, 32 de novo, 64 biparental, 128 uniparental, 256 not tested, 512 tested inconclusive.
Allele ID (ALLELEID)ClinVar's allele identifier (the VCF ID column holds the variation ID). CLNHGVS: the genomic HGVS expression; CLNVI: identifiers in other databases.
Oncogenicity (ONC)Since 2024, somatic variants: the oncogenicity classification (Oncogenic, Likely oncogenic, Uncertain significance, Likely benign, Benign) and SCI, somatic clinical impact (tiers I–IV, AMP/ASCO/CAP), each with its condition and review status keys.

gnomAD

AC, AN, AF, nhomaltCounts over high-quality genotypes only (GQ ≥ 20, DP ≥ 10, allele balance ≥ 0.2 for heterozygotes): allele count, allele number, allele frequency, and nhomalt, the number of individuals homozygous for the ALT allele (hemizygous on male chrX outside the PARs). _raw keys count all genotypes.
Groups (AF_nfe, AC_afr_XX…)The same per genetic ancestry group: afr African/African American, amr Admixed American, asj Ashkenazi Jewish, eas East Asian, fin Finnish, mid Middle Eastern, nfe Non-Finnish European, sas South Asian, ami Amish, remaining (oth in v2) the rest; _XX/_XY by karyotypic sex. Subsets (non_cancer, controls, non_neuro, non_topmed, non_ukb) exclude cohorts.
Filtering AF (faf95)Filtering allele frequency: the highest true population frequency still compatible, at 95 % confidence, with the observed allele count (Whiffin et al. 2017), computed per group; fafmax is the largest over groups. If faf95 exceeds the maximum credible frequency for a disorder (from prevalence, penetrance and heterogeneity), the variant is too common to cause it — the basis of ACMG BA1/BS1.
Group with max AF (grpmax, popmax)The group with the highest allele frequency (bottlenecked groups such as Finnish and Ashkenazi Jewish excluded), and its AC, AN and AF in AF_grpmax etc.
FiltersAC0: no high-quality ALT genotype; AS_VQSR/RF: failed the allele-specific VQSR or random-forest model; InbreedingCoeff: excess heterozygotes (F < −0.3). Flags lcr low-complexity region, segdup segmental duplication, non_par outside the pseudoautosomal regions.
CADD (Phred)Combined Annotation Dependent Depletion, scaled so 10 is the top 10 % of all possible substitutions by predicted deleteriousness, 20 the top 1 %, 30 the top 0.1 %.
REVELMissense pathogenicity ensemble score, 0–1. ClinGen's calibration (Pejaver et al. 2022) for PP3/BP4: ≥ 0.932 strong, ≥ 0.773 moderate, ≥ 0.644 supporting evidence of pathogenicity; ≤ 0.290 supporting, ≤ 0.183 moderate, ≤ 0.016 strong evidence of benignity.
SpliceAI max ΔThe largest predicted change in splice acceptor or donor probability (0–1) within 50 bp. The authors suggest 0.2 (high recall), 0.5 (recommended) and 0.8 (high precision) as cut-offs. Pangolin gives a similar splice score.
phyloPBase-wise conservation across species: positive values mean slower evolution than neutral (conserved), negative faster.
SIFT, PolyPhenOlder missense predictors: SIFT 0–1 with ≤ 0.05 "deleterious"; PolyPhen-2 0–1 with ≥ 0.85 "probably damaging" (HumDiv).

Annotators: VEP and SnpEff

VEP consequences (CSQ)One entry per affected transcript, comma-separated; each entry's fields are "|"-separated in the order the ##INFO=<ID=CSQ…Format: …> header line lists (Allele|Consequence|IMPACT|SYMBOL|Gene|Feature|…). Consequences are Sequence Ontology terms; IMPACT is HIGH (e.g. stop gained, frameshift, splice donor/acceptor), MODERATE (missense, in-frame indel), LOW (synonymous, splice region) or MODIFIER (non-coding).
SnpEff annotation (ANN)The same idea in SnpEff's fixed order: Allele|Annotation|Impact|Gene name|Gene ID|Feature type|Feature ID|Transcript biotype|Rank|HGVS.c|HGVS.p|… LOF/NMD mark predicted loss of function and nonsense-mediated decay.

BED and its relatives

BED (3–12 columns)chrom, chromStart, chromEnd (0-based, half-open), name, score (0–1000, shades the item when useScore=1), strand, thickStart, thickEnd (the coding part, drawn thick), itemRgb, blockCount, blockSizes, blockStarts (exons, relative to chromStart). A track line on top may give name, description, colour and assembly (db=).
narrowPeak (BED6+4)ENCODE peaks of point-source signal (transcription factors, ATAC): signalValue (overall enrichment, usually fold change over control), pValue and qValue (−log10; −1 when not computed; MACS2's qValue is the Benjamini–Hochberg FDR), peak (summit offset from chromStart; −1 when none). Score is 0–1000, often scaled from the p-value.
broadPeak (BED6+3)Broad enriched domains (H3K27me3, H3K36me3, H3K9me3): signalValue, pValue, qValue as in narrowPeak, without a summit.
gappedPeak (BED12+3)Broad regions made of narrower blocks (MACS2 --broad): BED12 whose thick part and blocks are the strong sub-peaks, then signalValue, pValue, qValue.
bedGraph, bigWigA value per interval. What it means depends on the pipeline: read coverage, reads per million (RPM/CPM), fold change over control, −log10 p-value of enrichment (ENCODE "signal p-value"), methylation fraction, conservation… The file name or track description usually says.
bedMethylPer-cytosine methylation (ENCODE; modkit for nanopore): BED9 + coverage (reads covering the base) + percent modified. modkit adds N_mod, N_canonical, N_other_mod, N_delete, N_fail, N_diff, N_nocall, and the modification code in the name column (m 5mC, h 5hmC, a 6mA).
interact, BEDPEPairs of regions (chromatin loops, enhancer–promoter links): BEDPE is chrom1, start1, end1, chrom2, start2, end2, name, score, strand1, strand2; UCSC's interact (BED5+13) adds value, experiment, colour and both regions' names and strands.
GFF3, GTFseqid, source, type (gene, mRNA/transcript, exon, CDS, UTR…), start, end (1-based, inclusive), score, strand, phase (bases to drop before the first codon of a CDS: 0, 1, 2), attributes (GFF3 ID=…;Parent=…; GTF gene_id "…"; transcript_id "…";).

Alignments: SAM, BAM, CRAM

FLAGBits: 1 paired, 2 properly paired (as the aligner expects for the library), 4 unmapped, 8 mate unmapped, 16 reverse strand, 32 mate reverse strand, 64 first of pair (R1), 128 second (R2), 256 secondary alignment, 512 failed QC, 1024 PCR or optical duplicate, 2048 supplementary (part of a split/chimeric alignment).
MAPQMapping quality, −10·log10 P(the read is placed wrongly); 255 when unknown. Aligners calibrate differently: BWA gives 0 to reads placed equally well elsewhere and up to 60; Bowtie2 up to 42; STAR uses 255 for unique, 3, 1 and 0 for 2, 3–4 and ≥ 5 placements.
CIGARHow the read aligns: M aligned (match or mismatch), = match, X mismatch, I insertion, D deletion, N skipped reference (an intron in RNA-seq), S soft clip (bases kept in the read but not aligned), H hard clip, P padding.
TLENTemplate length: the fragment length from the leftmost to the rightmost mapped base of a pair, positive for the leftmost read.
TagsNM edit distance to the reference; MD the mismatching reference bases; AS/XS alignment score of this and the next-best placement; SA supplementary (split) alignments; MC the mate's CIGAR; MQ the mate's MAPQ; RG read group; NH number of loci the read maps to and HI which one; XA BWA's alternative hits; RX/MI UMI and molecule ID; CB/UB 10x cell barcode and UMI; MM/ML base modifications (methylation).
Header@HD SO: sort order; @SQ reference sequences with lengths (and AS: assembly, M5: checksum); @RG read groups (SM sample, LB library, PL platform, PU flowcell and lane); @PG the programs that produced the file, in order, with versions and command lines — the pipeline's history (alignment, sorting, duplicate marking, filtering).

Hi-C: Cooler

binsThe genome cut into fixed-size bins: chrom, start, end and, once balanced, weight (the balancing factor; null for bins masked as unreliable).
pixelsThe contact matrix's non-zero entries: bin1_id, bin2_id (upper triangle) and count, the raw number of read pairs linking the two bins. Balanced contacts are count × weight1 × weight2 (iterative correction, ICE).
.mcool, .scoolOne Cooler per resolution (a tab per resolution), and one per single cell.
Observed / expectedContacts divided by the average at the same genomic distance: shows loops and compartments above the strong decay with distance.

Sequences: FASTA and FASTQ

FASTAName, description and sequence. IUPAC codes: N any base, R A/G, Y C/T, S G/C, W A/T, K G/T, M A/C, B not A, D not C, H not G, V not T. Lower case is usually soft-masked repeat sequence. With a .fai index a region gives one row per window: its sequence.
FASTQ qualityOne character per base: Phred quality Q = ord(char) − 33 (Sanger / Illumina 1.8+), the error probability being 10−Q/10: 5 is Q20 (1 %), ? Q30 (0.1 %), I Q40. Old Illumina files (1.3–1.7) use an offset of 64.
